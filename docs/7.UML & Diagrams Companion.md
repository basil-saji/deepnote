It uses the active editor buffer and does not require SearchService or pgvector in the first version.

# 9. Sequence Diagram — AI Chat



```text
User -> EditorPanel: Open AI sidebar
EditorPanel -> AIAssistantPanel: Show panel for active note
User -> AIAssistantPanel: Submit question
AIAssistantPanel -> AIAssistantController: ask(question, activeNoteId)
AIAssistantController -> EditorPanel: Read current editor buffer
AIAssistantController -> AIAssistantService: answer(noteTitle, noteText, recentTurns, question)
AIAssistantService -> ContextManager: Prepare bounded context
ContextManager --> AIAssistantService: Prompt/messages or context-limit error
AIAssistantService -> ChatModelClient: Generate answer
ChatModelClient -> Ollama: Local chat request
Ollama --> ChatModelClient: Answer
ChatModelClient --> AIAssistantService: Answer
AIAssistantService --> AIAssistantController: Answer
AIAssistantController -> AIAssistantPanel: Update on EDT
User -> AIAssistantPanel: Collapse/reopen
AIAssistantPanel -> AIAssistantPanel: Retain session messages
```

Generation runs in a background worker, not the EDT. Long notes require explicit context-limit handling. No chat-specific database tables are added in the MVP.

# 12. Notes

- TXT files are the Source of Truth.
- PostgreSQL stores metadata and semantic chunks.
- Semantic indexing runs using `IndexWorker` (a `SwingWorker`) to keep the UI responsive.
- If a save arrives while `IndexWorker` is already running, it is not queued — `pendingIndex` is set and the worker re-runs once on completion (Repeated Save Handling, see SDD §8.1).
- Semantic search falls back to keyword search when Ollama is unavailable.
- Search results are displayed as preview cards containing the most relevant chunk.
- The AI sidebar uses the active note plus recent in-memory turns and remains separate from semantic search.
- Chat generation runs off the EDT; the panel can collapse without clearing session state.
- The first AI version does not add chat tables to the ERD.
- These diagrams are simplified for an academic Object-Oriented Programming project while accurately representing the implemented architecture.
