# 1. Introduction

This document contains the primary UML and architecture diagrams for DeepNote v0.1. Target UI diagrams use JavaFX 27, FXML, Java controllers and AtlantaFX 3.0.0 on Java 25 LTS; database diagrams describe the later PostgreSQL/pgvector phase.

The diagrams provide a visual overview of the software structure, object relationships, workflows, and deployment. They complement the Software Design Document (SDD).

The JavaFX/FXML controller layer calls existing services. The database branch shown below is planned only; the current foundation uses TXT files and local keyword search. `SearchService` is drawn as a future strategy boundary for semantic ranking:

```
SearchService
      │
      ▼
  Searcher
<<interface>>
      │
   ┌──┴──┐
   ▼     ▼
VectorSearcher   TextSearcher
```

**Purpose**

Illustrates the major software components and their interactions, including the `Searcher` strategy interface that `SearchService` delegates to at runtime.

The optional AI chat is a separate path:


EditorPanel → AIAssistantController → AIAssistantService → ContextManager → ChatModelClient → local Ollama chat model.

It uses the active editor buffer and does not require SearchService or pgvector in the first version.

# 9. Sequence Diagram — AI Chat



```text
User -> EditorTab: Open right-side AI panel
EditorTab -> AIAssistantPanel: Show panel for active note
User -> AIAssistantPanel: Submit question
AIAssistantPanel -> AIAssistantController: ask(question, activeNoteId)
AIAssistantController -> EditorTab: Read current editor buffer
AIAssistantController -> AIAssistantService: answer(noteTitle, noteText, recentTurns, question)
AIAssistantService -> ContextManager: Prepare bounded context
ContextManager --> AIAssistantService: Prompt/messages or context-limit error
AIAssistantService -> ChatModelClient: Generate answer
ChatModelClient -> Ollama: Local chat request
Ollama --> ChatModelClient: Answer
ChatModelClient --> AIAssistantService: Answer
AIAssistantService --> AIAssistantController: Answer
AIAssistantController -> AIAssistantPanel: Update on JavaFX Application Thread
User -> AIAssistantPanel: Collapse/reopen
AIAssistantPanel -> AIAssistantPanel: Retain session messages
```

Generation runs in a JavaFX `Task`/`Service`, not the Application Thread. Long notes require explicit context-limit handling. No chat-specific database tables are added in the MVP.

# 12. Notes

- TXT files are the Source of Truth.
- PostgreSQL stores metadata and semantic chunks.
- Semantic indexing is planned for the database phase and will use JavaFX `Task`/`Service`.
- Local keyword search is the current search behavior.
- Search ranking and semantic preview cards are planned database-phase functionality.
- The right-side AI panel uses the active note plus recent in-memory turns and remains separate from search.
- Chat generation runs off the JavaFX Application Thread; the panel can collapse without clearing session state.
- The first AI version does not add chat tables to the ERD.
- These diagrams distinguish the implemented TXT/keyword foundation from planned database behavior and the target JavaFX architecture.
